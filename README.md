This repository contains [FlatGeobuf](https://flatgeobuf.org/) files of the UTM 10x10-km^2^ grid of the Iberian Peninsula, as well as the R code that was written to generate them, from the grids described in the paper "*A Geoplatform for improving accessibility to environmental cartography*" by Pablo Sastre, Pere Roca, Jorge M. Lobo & EDIT co-workers (<https://doi.org/10.1111/j.1365-2699.2008.02070.x>).

Please **cite the sources / authors** in any use you make od these materials.
